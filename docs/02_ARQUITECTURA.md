# Resumen de Arquitecturac: Chavales legales

## Especificaciones servidor
Las especificaciones del servidor son las siguientes:
- Dominio: http://chavaleslegales.fdi.ucm.es/
- Procesadores: 4 CPUs.
- RAM: 8GB RAM.
- Almacenamiento: 40GB.
- Sistema Operativo: Ubuntu server 24.04 LTS (22.04).
- *Root access* para poder instalar lo que queramos.
- *Software* adicional del servidor:
    - Docker.
    - Docker compose.
    - Nginx.
    - Git.
    - Node.js.
    - npm.
    - Un panel como Coolify o CapRover.
